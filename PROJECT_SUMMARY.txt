┌──────────────────────────────────────────────────────────────────┐
│  🎨 USER FLOW - PASSWORD RESET                                   │
└──────────────────────────────────────────────────────────────────┘

1. User clicks "Forgot password?" on signin page
   ↓
2. Modal opens → Enter email → Click "Send Code"
   ↓
3. Backend generates random 6-digit code
   ↓
4. Code saved to database (expires in 15 min)
   ↓
5. Email sent via SMTP with code
   ↓
6. User receives email with code
   ↓
7. User enters code + new password in modal
   ↓
8. Backend verifies code (not expired, not used)
   ↓
9. Password updated in Supabase Auth
   ↓
10. Code marked as "used" in database
   ↓
11. Success message → User can signin with new password ✅
